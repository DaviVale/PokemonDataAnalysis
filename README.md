# Overview

As a software engineer, I want to improve my skills in Python and learn how to analyze data using Pandas. This project helped me understand how to work with datasets, organize information, calculate statistics, and create charts.

The dataset I am analyzing contains 800 Pokemon records and 13 columns, including their names, types, attack, defense, speed, and other information.

[Pokemon Dataset](https://github.com/GauravSahani1417/Kaggle-Datasets/blob/master/Pokemon.csv)

My purpose for writing this software is to learn how to use Python to analyze data and answer questions about Pokemon. I also wanted to create an interactive program where users can explore the dataset, search for Pokemon, view statistics, and visualize the results in a chart.

[Software Demo Video](http://youtube.link.goes.here)


# Data Analysis Results

**Question 1: Which Pokemon type appears most often?**

Water is the most common primary type, with 112 records out of 800. This represents 14% of the dataset.

**Question 2: What is the average attack value of all Pokemon?**

The average attack value is 79.0. The highest attack value is 190, and the lowest is 5.

**Question 3: Which Pokemon type has the highest average attack?**

Dragon has the highest average attack value, with an average of 112.12.

# Development Environment

I used Visual Studio Code to write and test my code. I also used Git and GitHub to manage my project and store my source code.

The programming language I used was Python. I used the following libraries:

* Pandas - to read the CSV file, filter, sort, group, and analyze the data.
* Matplotlib - to create a bar chart showing the number of Pokemon by primary type.
* mplcursors - to display the Pokemon type and quantity when hovering over the bars in the chart.
